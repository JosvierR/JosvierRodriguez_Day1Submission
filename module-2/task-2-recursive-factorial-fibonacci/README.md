# Task 2

## Question

(Recursive Factorial & Fibonacci Utility): Write a class `MathUtils` containing two static recursive methods: `long factorial(int n)` and `long fibonacci(int n)`. Add input validation to throw an IllegalArgumentException for negative inputs.

## How I understand it

For factorial and Fibonacci, the method calls itself with a smaller value until it reaches a base case that stops the recursion. The negative-number check is just there to prevent invalid inputs.

## Verified output

```text
Factorial of 5: 120
Fibonacci of 5: 5
```
